Блог.

Как строим RED TEAM LAB: privacy-native AI-терминал. Локальные модели, P2P без облака.

01.10.2026 · AI

AI-агент прямо в телефоне. Без облака.

RED TEAM LAB учится думать сам:

  • получает задачу и раскладывает её на шаги
  • сам выполняет bash-команды
  • смотрит на ошибку, запоминает и в следующий раз делает иначе

Память агента лежит в SQLite на самом устройстве. Модель (Qwen ~2B, GGUF) крутится локально через llama.cpp. Ни одна команда и ни один файл не уходят на чужой сервер.

Под капотом: Flutter для интерфейса, Rust для ядра.

Честно: это MVP, агент сейчас в работе. 2B-модель на телефоне пока думает медленно, ускоряем. Зато всё твоё остаётся твоим.

01.10.2026 · Терминал

Что уже работает на телефоне

  • Живой шелл. Не эмуляция, команды реально выполняются.
  • Плитки окон как в Hyprland: несколько терминалов рядом, границы тянутся.
  • Guard. Каждая команда проходит проверку перед запуском. rm -rf / блокируется сразу, опасные требуют подтверждения.
  • Тёмный cyberpunk-интерфейс, красный акцент.

Дальше: busybox для полного набора команд, нормальный PTY, AI-подсказки в строке ввода, потом синхронизация между устройствами по P2P без облака.

Пока Android. Windows, Linux и macOS на очереди.

01.10.2026 · English

A privacy-native AI terminal

Most AI dev tools send your commands, files and shell history to someone else's server. RED TEAM LAB runs the model on your device and keeps everything there.

Works today (Android, MVP)

  • Real shell session, not an emulator
  • Tiling window layout inspired by Hyprland
  • Command guard in Rust: rm -rf / → BLOCK, risky ops → confirm

In progress

  • On-device agent: plans a task, runs bash, stores failures in local SQLite memory and adjusts next time
  • Local inference: GGUF models (Qwen ~2B, Q4) via llama.cpp, memory-mapped; heavier reasoning can optionally go to Claude API, opt-in
  • MESH: device-to-device sync without a server, signed packets, optional routing over Tor (arti)

Stack
