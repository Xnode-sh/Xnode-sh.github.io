# Xnode-sh.github.io

Статический сайт (GitHub Pages) на домене [redteam.is-a.dev](https://redteam.is-a.dev) — проект RED-TEAM-LAB by Xnode, Telegram: [@xnode_sh](https://t.me/xnode_sh).

## Что внутри

- `index.html` — главная страница (Termux, OSINT и LLM-агенты на Python)
- `studio.html` — страница Xnode Content Studio
- `privacy.html`, `terms.html` (и одноимённые папки) — политика конфиденциальности и условия
- `CNAME` — привязка домена
- `tiktok*.txt` — файлы верификации домена для TikTok

## Запуск

Сборки нет: чистый HTML/CSS. Для локального просмотра откройте `index.html` в браузере
или выполните `python3 -m http.server` в корне репозитория.
